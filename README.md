# Linked Lists

A from-scratch beginner project that turns "pointers confuse me" into "I can do pointer surgery in my head." You build a singly linked list, then a doubly linked list, implementing insertion, deletion, and traversal, and then master the pointer tricks interviewers love most — iterative reversal, the fast/slow runner technique for the middle node, and Floyd's tortoise-and-hare cycle detection. Each step adds a module with pytest tests and a README, and the Socratic dialogue teaches the WHY behind every pointer move and its time and space complexity.

Built step-by-step with [KhwajaLabs Build](https://khwajalabs.com).

## Stack
- Python
- pytest
- Linked Lists
- Pointers
- Big-O
